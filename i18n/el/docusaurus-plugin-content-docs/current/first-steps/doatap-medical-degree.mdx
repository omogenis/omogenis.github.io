# Αναγνώριση Πτυχίων Ιατρικής & Οδοντιατρικής (ΔΟΑΤΑΠ): Οδηγός Προετοιμασίας

Για τους ιατρούς και οδοντιάτρους με πτυχία εκτός Ε.Ε. (Ηνωμένο Βασίλειο, Ρουμανία, Βουλγαρία, Ιταλία, Ρωσία, Αρμενία, Γεωργία, κ.ά.), περιλαμβανομένων των ομογενών, η επιτυχής παρακάθηση στις γραπτές εξετάσεις του **ΔΟΑΤΑΠ** αποτελεί το υποχρεωτικό στάδιο αναγνώρισης του πτυχίου.

:::note Ορθότητα Εξετάσεων
Οι γραπτές εξετάσεις του ΔΟΑΤΑΠ διεξάγονται αποκλειστικά στην **ελληνική γλώσσα** με τη μορφή ερωτήσεων πολλαπλής επιλογής (multiple-choice) και εφαρμόζουν **αρνητική βαθμολόγηση (-0.20 βαθμοί ανά λανθασμένη απάντηση)**. 
:::

Η πλατφόρμα **[Ιατρέ!](https://iatre.gr)** εφαρμόζει μια διπλή διαδικασία επαλήθευσης για κάθε ερώτηση της βάσης δεδομένων (7.000+ ερωτήσεις Ιατρικής και 5.000+ ερωτήσεις Οδοντιατρικής).
