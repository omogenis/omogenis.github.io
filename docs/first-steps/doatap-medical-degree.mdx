# Признание дипломов врача и стоматолога в Греции (ΔΟΑΤΑΠ): Руководство по подготовке

Для врачей и стоматологов с дипломами не из стран ЕС, выпускников зарубежных медицинских вузов (Россия, Украина, Беларусь, Казахстан, Армения, Грузия, Румыния и др.), в том числе соотечественников и граждан Греции, желающих работать в Греции, сдача письменных экзаменов **ΔΟΑΤΑΠ** является обязательным этапом нострификации диплома.

:::note Особенности экзамена
Письменные экзамены ΔΟΑΤΑΠ проводятся исключительно на **греческом языке** в формате вопросов с множественным выбором (multiple-choice). На экзамене действует **негативная система оценивания (-0.20 балла за каждый неверный ответ)**. Освоение греческой медицинской терминологии является ключевым фактором успешной сдачи.
:::

## Пошаговый план подготовки для врачей

:::info План действий
1. **Подача документов**: Зарегистрируйте заявление на портале [e-doatap.gr](https://www.doatap.gr).
2. **Начните готовиться**: Начните с фундаментальных дисциплин (анатомия, физиология, фармакология) для усвоения терминов.
3. **Параллельный перевод**: Включите функцию перевода на [Iatre!](https://iatre.gr), чтобы сопоставить привычные медицинские понятия с греческой терминологией.
4. **Тренировка с таймером**: Проходите контрольные тесты с включенным симулятором штрафных баллов за 2–3 недели до экзамена.
:::
