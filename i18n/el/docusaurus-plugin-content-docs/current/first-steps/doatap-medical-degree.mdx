# Αναγνώριση διπλωμάτων ιατρού και οδοντιάτρου στην Ελλάδα (ΔΟΑΤΑΠ): Οδηγός προετοιμασίας

Για ιατρούς και οδοντιάτρους με πτυχία εκτός χωρών Ε.Ε., αποφοίτους ξένων ιατρικών πανεπιστημίων (Ρωσία, Ουκρανία, Λευκορωσία, Καζακστάν, Αρμενία, Γεωργία, Ρουμανία κ.ά.), συμπεριλαμβανομένων ομογενών και Ελλήνων πολιτών που επιθυμούν να εργαστούν στην Ελλάδα, η επιτυχής παρακάθηση στις γραπτές εξετάσεις του **ΔΟΑΤΑΠ** αποτελεί υποχρεωτικό στάδιο αναγνώρισης (ισοτιμίας) του πτυχίου.

:::note Ιδιαιτερότητες των εξετάσεων
Οι γραπτές εξετάσεις του ΔΟΑΤΑΠ διεξάγονται αποκλειστικά στην **ελληνική γλώσσα** με τη μορφή ερωτήσεων πολλαπλής επιλογής (multiple-choice). Στις εξετάσεις ισχύει **σύστημα αρνητικής βαθμολόγησης (-0,20 μόρια για κάθε λανθασμένη απάντηση)**. Η κατάκτηση της ελληνικής ιατρικής ορολογίας αποτελεί τον καθοριστικό παράγοντα επιτυχίας.
:::

:::
